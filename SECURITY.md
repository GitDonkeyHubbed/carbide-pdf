# Security Policy

## Reporting a vulnerability

Report security problems privately. Do not open a public issue or pull request for them.

Use the "Report a vulnerability" button on the repository's Security tab. It opens a private security advisory that only the maintainers can see.

Include the following in your report:

- The version or commit you used.
- The steps to reproduce the problem.
- What you expected to happen, and what happened.
- A sample file, if you can share it safely. Remove personal or confidential content first. Do not send real signing keys, certificates or passwords.

## Supported versions

Only the latest version on the `main` branch is supported. Fixes are made on `main`.

## Scope

Carbide PDF opens untrusted PDF files, and it handles digital signatures and passwords. Reports about those areas are especially welcome.
